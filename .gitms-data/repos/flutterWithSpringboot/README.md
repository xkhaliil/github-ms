# flutterWithSpringboot

Flutter client with a Spring Boot backend for university management

## What it does
The repository contains a Flutter client (`client`) with pages and services for signing in/up, and managing departments, classes, subjects, and students (see `lib/pages` and `lib/services`). It also contains a Spring Boot server project named `university-management` under `server/`, suggesting the two communicate over an API, though the exact endpoints could not be verified from the evidence available.

## Tech stack
- Flutter / Dart (client, per `pubspec.yaml`)
- Java / Spring Boot (server, per `pom.xml` in `server/university-management`)
