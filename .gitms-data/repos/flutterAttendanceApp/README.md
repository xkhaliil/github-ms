# flutterAttendanceApp

Flutter mobile app with a Spring Boot backend for tracking university attendance

![Language](https://img.shields.io/badge/language-Dart-blue)

## What it does

This repository contains a Flutter client (`client/`) that targets Android, iOS, web, Linux, macOS, and Windows, alongside a Java/Maven backend project (`university-management/`) built with Spring Boot (using the Maven wrapper). The client includes `lib/models`, `lib/pages`, and `lib/services` directories, suggesting a typical Flutter app structure with data models, UI pages, and service classes. The exact attendance-tracking logic, screens, and API endpoints could not be confirmed because entry-point source files were not readable in this evidence bundle.
